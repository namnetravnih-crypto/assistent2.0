# Ассистент — заполнение бланков по карте партнёра

Статический сайт (HTML + JS). Серверная часть не нужна, все файлы обрабатываются в браузере.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите в корень файлы: `index.html`, `style.css`, `engine.js`, `app.js`.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Библиотеки JSZip и pdf.js подгружаются с cdnjs, поэтому нужен интернет.

## Как пользоваться
1. Загрузите карту партнёра (.docx, .xlsx, .pdf с текстом, .txt) или вставьте текст. Проверьте распознанные поля.
2. Загрузите все бланки (.docx, .xlsx). Для каждого можно выбрать режим: «заполнить всё» или «только наименование и подписант».
3. Нажмите «Заполнить». На выходе столько же файлов, сколько загружено, плюс ZIP со всеми.
4. Галочка «Выделять жёлтым…» включена по умолчанию.

## Что делает движок (engine.js)
- Таблицы: «подпись | пустая ячейка» и «шапка / пустая строка под ней».
- Абзацы: «Подпись: ______», «ИНН ………», подчёркнутые пробелы, плейсхолдеры `[ИНН]`, `{{ИНН}}`.
- Блок подписи: «/ ______ /» → Иванов И.И.; «(ФИО)», «(должность)» под линией; линия «подпись» и «М.П.» не трогаются.
- Дата ««__» ______ 20__ г.» заполняется, если указана дата документа.
- Шрифт и размер берутся из соседнего текста, жирность подписи в значение не переносится.

## Ограничения
- Старые форматы .doc / .xls и сканы PDF не поддерживаются: пересохраните в .docx / .xlsx.
- Формулировка «в лице …» требует родительного падежа: ФИО вводится вручную в карте (должность подставляется автоматически).
- В Excel неизвестные поля подсвечиваются, только если пустая ячейка справа уже есть в файле.
- Всегда просматривайте результат перед отправкой: правила эвристические.
